#  Starbucks Consumer Sentiment Analysis

A data-driven sentiment analysis project exploring customer perceptions of **Starbucks** across **Twitter (X)**, **Reddit**, and **Google Maps Reviews** between **December 1, 2023 – March 15, 2024**. This project uses **Natural Language Processing (NLP)** techniques and the **VADER sentiment model** to uncover key themes, emotional trends, and strategic opportunities for the brand.

## Project Highlights

- Cross-platform sentiment analysis using VADER
- Real-time data collection via APIs and Apify
- Seasonal segmentation: Pre-Holiday, Post-Holiday, Post-Valentine’s
- Comparison with Costa Coffee for benchmarking
- Strategic recommendations for improving customer experience and brand value

## Tech Stack

- **Python**, **Pandas**, **NLTK**, **Matplotlib**, **Seaborn**
- **VADER** for sentiment scoring
- **PRAW** for Reddit API access
- **Apify** for scraping Twitter and Google reviews
